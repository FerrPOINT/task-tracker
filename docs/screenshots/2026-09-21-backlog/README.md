# Backlog: мобильные строки задач

Локальная проверка 21.09.2026 в Chromium на настоящем `ProjectBacklogPage` с изолированными GET-ответами. Временный QA-экран удалён после проверки; реальные данные не менялись.

- `before-320/375.*`: исходная строка обрезала название до нескольких букв; ссылка с `display: contents` имела прямоугольник 0×0.
- `after-light/dark-320/375/1920/2560.*`: ключ и название находятся в одной явной ссылке, на mobile название занимает до двух строк, метаданные расположены ниже; desktop остаётся однострочным.
- 8 сценариев после исправления: 320/375/1920/2560 px, светлая и тёмная темы. Во всех нет переполнения страницы и серьёзных/критических замечаний axe-core по WCAG 2.0/2.1 A/AA.
- Фактические цели кнопок на mobile не меньше 40×40 px; кнопка меню задачи явно задаёт этот размер. Desktop-кнопки редактирования спринта 28×28 px не менялись.
- Доступное имя каждого меню содержит ключ своей задачи (`TT-101/102/103`), что позволяет различать их при навигации скринридером.
- JSON-файлы содержат размеры кнопок и прямоугольник ссылки до/после.

Это компонентная проверка без реального SSO и общего shell; после выкладки нужна приёмка в полном пользовательском маршруте.
