# Адаптивная доска: локальная проверка

Скриншоты сняты 21.09.2026 в Chromium на настоящем `ProjectBoardPage` с изолированными ответами GET API. Временный QA-экран удалён после проверки; реальные данные не изменялись. Имена файлов: `<число колонок>-<ширина>-<тема>.png`.

- 30 сценариев: 2 и 5 статусов, 375/768/1280/1920/2560 px, светлая/серая/тёмная темы.
- На мобильном экране видна одна выбранная колонка; выбор пятого статуса работает.
- На десктопе колонки остаются в одной строке. При нехватке места область прокручивается; проверена клавиша `ArrowRight` после фокусировки.
- Нет горизонтального переполнения страницы и серьёзных/критических замечаний axe-core по WCAG 2.0/2.1 A/AA.
- Измерения для каждого сценария сохранены в `qa.json`.

Это компонентная проверка без реального SSO и боковой панели приложения; после выкладки нужна проверка в полном пользовательском маршруте.
