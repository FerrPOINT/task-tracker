# Проверка назначения исполнителей

Снимки сделаны в Chromium из реальных компонентов создания и редактирования
задачи с изолированными GET-ответами проектов, активного центрального каталога
пользователей и workflow. Для каждой формы сохранены full-page кадры 375, 1920
и 2560 px в тёмной, светлой и серой темах соответственно. `create-375-error.png`
показывает отказ каталога и действие повтора. `qa.json` фиксирует отсутствие
горизонтального переполнения и serious/critical axe-нарушений.

Ни один изменяющий API-запрос не выполнялся. Это компонентная проверка, не
авторизованная live SSO/API-приёмка рабочего стенда.
