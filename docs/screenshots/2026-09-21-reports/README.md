# Отчёты: доступные данные графиков

Локальная проверка 21.09.2026 на настоящем `ReportsPage` в Chromium с изолированными ответами GET API. Временный QA-экран после проверки удалён; реальные данные не изменялись. Имена файлов: `<вид отчёта>-<ширина>-<тема>.png`.

- 24/24 сценария: 4 вида отчётов, 375/1920/2560 px, светлая и тёмная темы.
- Для каждого графика найдена доступная таблица с теми же числовыми данными; сам график скрыт от дерева доступности.
- На широком экране рабочая ширина отчётов не превышает 1280 px; длинные оси не растягиваются на весь viewport.
- Нет горизонтального переполнения страницы, ошибок JavaScript, серьёзных/критических замечаний axe-core по WCAG 2.0/2.1 A/AA и изменяющих API-запросов.
- Сводка сценариев сохранена в `qa.json`.

Это компонентная проверка без реального SSO и общего shell; после выкладки нужна приёмка в полном пользовательском маршруте.
