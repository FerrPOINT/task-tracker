# Доработки UI/UX 2026-10-14

UX-06/09. Создание первого проекта на dashboard и в форме задачи использует существующий ProjectFormDialog. После подтверждения каталог обновляется, проект выбирается, ввод задачи сохраняется; отказ создания остаётся в диалоге. Вход и callback SSO используют Base.

Общие контракты и тексты: [стандарт Base](https://github.com/FerrPOINT/services-base/blob/6a210dca877b5e3e04f01c619c7ca309b5c1bae3/docs/platform/UI_UX_STANDARD.md). UI pin: `6a210dca877b5e3e04f01c619c7ca309b5c1bae3`; SDK и skills pins сохранены.

Интегрирован main `e276fdc` с сохранением изменённых полей настроек проекта,
серверным обновлением нетронутых полей и backend-валидацией имени. При повторном
ревью устранена постоянная локальная копия созданного проекта: query cache
принимает ответ создания, затем свежий каталог обновляет имя или блокирует
недоступный проект. Две регрессионные проверки воспроизводили ошибку до фикса.

Frontend: 390 тестов; TypeScript/lint, build, frozen lockfile, OpenAPI и
проверка Prettier с учётом локальных окончаний строк. Историческая IAB-проверка
общего анонимного входа на 320/375/1920/2560 не подтверждает живой SSO нового
кандидата. Шесть API-fixture сценариев прошли в Chromium/Firefox/WebKit:
создание проекта с отказом/повтором и обновлением каталога; dashboard, настройки
проекта, board и создание задачи. SSO fixture использует реальный HTTP redirect.
Проверены скриншоты
375/1920/2560 и effective theme contrast. Эти сценарии учитываются отдельно от
полной приёмки с реальным Auth и межпродуктовыми переходами.

Зависимость: [Base PR #206](https://github.com/FerrPOINT/services-base/pull/206). Кандидат поставляется draft: полная межпродуктовая IAB-приёмка, SSO и 30 направлений переключения ещё не подтверждены. Backend побайтно соответствует проверенному исходнику PR #155 и текущему main; неизменённые Rust-гейты переиспользуются. GitHub CI учитывается по точному head; отсутствие запуска из-за billing не объявляется PASS.

Работа и native QA выполняются в PDLC2 без новых Docker-групп. Merge и установка исключены; установка — отдельная задача.
