# Проверка выхода после внедрения общего Header

## Область

Обновить существующий no-mock тест глобального выхода из шести приложений.
Продуктовые auth API, роли, данные и runtime-конфигурация не меняются.

## Изменение

- Дождаться готового переключателя сервиса после SSO-перехода.
- Определять наличие меню «Аккаунт» по фактическому доступному control,
  а не по фиксированному списку продуктов.
- Сохранить проверку server-rendered ссылки Workflow и прямой кнопки старых shell.
- Сохранить все проверки отзыва браузерной сессии, sibling-запроса и сохранности PAT.

## Приёмка

Один непрерывный прогон существующего теста против живых сервисов, без моков и
повторов; frontend unit, typecheck и lint. Backend не изменяется.
GitHub Actions не запускаются; используется локальная проверка.
