# Очистка навигации

Основная навигация: дашборд, проекты, поиск. В проекте остаются доска, бэклог и отчёты проекта; корзина и настройки доступны из меню действий группы и карточки проекта, включая компактную панель. Глобальный /reports сохраняется. Администрирование находится в «Служебном». Все переходы сохраняют подтверждённый Namespace и область project_scope=all.

Функции, данные, API и права доступа сохраняются. Служебная группа свёрнута по умолчанию, раскрывается при прямом входе и допускает ручное сворачивание. На desktop и mobile используется одно состояние. Проверки: точные ресурсы при одинаковых названиях, старые ссылки, Back/Forward, all-projects scope, доступность, роли и narrow/wide UI.
