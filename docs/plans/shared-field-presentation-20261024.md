# Общие подписи полей Base

## Изменение

Формы проекта, спринта, задачи и метаданных используют публичный Label вместо локального
оформления 17 полей в четырёх файлах. Всего перенесено 17 подписей. Текст, htmlFor/id,
required, значение, обработчики, запросы и права сохраняет продукт.
Внешняя компоновка не переносится в библиотеку.

Первый срез использовал UI producer `8efc6c8d62b7d2c152b007215d6ce91f4c8f8d17` (0.3.1).
Label существовал ранее; нового API или зависимости для этих подписей нет.
SDK/skills pins сохранены; cached offline frozen install уже подготовленного
UI-пакета прошёл без обновления внешних версий.

## Проверка

Прошли 34 scoped test cases затронутых форм/экранов, scoped ESLint и
существующий primitive/choice contract. AST-сопоставление до/после не обнаружило
изменений вне импорта, тега подписи и её оформления.

Общий маршрут проверен в IAB на настоящей форме спринта Tracker: три темы,
standard/large и 320/375/1920/2560. Подписи имеют 14/16 px из BrandingScope
внутри Dialog Portal; htmlFor сохраняет focus и исходный callback получает
введённые данные. Это 24 source-composition проверки с синтетическим onSubmit,
не приёмка backend этого продукта. Полная новая сборка и hosted CI ещё открыты.

## Составные поля

Следующий срез заменяет обёртки: четыре FormField, включая динамические поля задачи; скопированные descendant min-height удалены.
Текст, прежние handlers/value/required/disabled и продуктовые условия сохранены;
семантические JSX props сопоставлены по AST. Native label больше не содержит
одновременно поле поиска и потенциальную кнопку очистки. Вместо локальной
типографики используется готовый контракт Base, без нового публичного API.

Текущий UI pin — `948b492b36ff2c95215d43cf945f15a849d593f3`. Его 772 поставляемых файла совпадают с ранее
проверенным архивом; двоичные assets сравниваются без нормализации. Новый producer
добавляет только development guard. Поэтому пять неизменных установок сохранены,
а AI Hub обновляет только dependency URI: frozen offline install, один reused
package, без downloads и обновления версий. У шести потребителей подтверждены
CLI check и единый React peer graph. SDK/skills не менялись.

Прошли 25 scoped cases текущих затронутых экранов. Все пять React-владельцев
вместе с Fleet дали 210 уникальных product cases, отдельно Base — 44 contract
cases. IAB Admin подтвердил 24 сочетания темы/масштаба/ширины, native required,
min/max, focus и ввод; токен не выпускался. IAB AI Hub подтвердил 12 сочетаний,
открытие Select через подпись, сохранение выбора и обновление трёх примеров;
код не исполнялся, inference не запускался. Это проверки source-compositions
с синтетическим read-only транспортом, не authenticated runtime acceptance.

Новые frontend-сборки, полный интеграционный gate и hosted CI остаются открытыми.
Наличие development guard не объявляется доказательством визуальной полноты.

## Ошибки формы и связь с контролом

Следующий срез использует семь FormField Base: четыре поля спринта и три поля
настройки custom field. Ошибка диапазона дат теперь принадлежит полю окончания,
ошибка пустого списка вариантов — полю вариантов. aria-invalid и aria-describedby
формирует Base; сравнение дат, разбор запятых, disabled и payload сохраняет Tracker.
Обязательность имени сохранена, у вариантов не добавляется native required.
Ошибки сохранения спринта и сверки Wiki отображаются готовым inline Notice;
локальный text-rose-500 удалён. Ошибка команды не получает page-readiness hook.

26 адресных cases трёх файлов прошли, включая три новых regression cases.
Новые assertions сначала падали на отсутствующей связи ошибки и live-region;
первая проверочная попытка с неточными текстами fixture сохранена отдельно.
Проверены допустимые соседние значения, сохранность ввода, отсутствие автоматической
записи и исходные create/edit payloads. Scoped ESLint, Prettier и choice/primitive
contract прошли. Полный route gate по-прежнему требует owner manifest, а не
фиктивного результата проверки.

IAB проверил настоящие SprintFormDialog и ProjectCustomFieldsPage из собственного
checkout: 12 сочетаний трёх тем и четырёх ширин для каждой формы. Ошибки связаны
с контролами, 40/44 px сохранены, горизонтального переполнения нет. Дополнительный
mobile large-показ Dialog Portal даёт Label 16 px. Исправление вариантов убирает
ошибку и включает действие без записи. Playwright fill не применил native даты;
успешный повтор через AX setValue подтверждён фактическими ISO-значениями DOM.
Использован synthetic read-only transport; установленный API не проверялся.
Собственные сервер и вкладка закрыты. Это не настоящий browser zoom 200%.

UI pin, SDK/skills, HTTP API и зависимости в этом срезе не меняются. Повторная
сборка неизменного Base и Storybook не выполнялась. Итоговый frontend gate и
публикация кандидата остаются отдельными незавершёнными стадиями.
